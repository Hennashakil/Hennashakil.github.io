whycant

C · Linux · GitHub Actions

“Permission denied” tells you that access failed. whycant tells you where, why, and the safest fix.

  • Walks a path like the kernel does, one folder at a time, through symlinks, read-only and noexec mounts, and POSIX ACLs.
  • Checked against the real kernel: 800 test cases in CI must give the same answer Linux gives, also under AddressSanitizer and UBSan.
  • Safe advice by design: it ranks fixes from narrowest to widest, never suggests chmod 777, and refuses to help open password files or root-level groups like docker.
  • Released like real software: a tag push builds a hardened binary and a .deb, and publishes them with checksums.
